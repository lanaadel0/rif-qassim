# ريف القصيم | RIF Qassim

نموذج أولي تفاعلي لمنصة ريف القصيم.

## الصفحات

- `index.html` — الصفحة الرئيسية
- `destinations.html` — الوجهات
- `destination.html` — تفاصيل الوجهة
- `experiences.html` — التجارب
- `booking.html` — الحجز
- `business.html` — للملاك
- `assessment.html` — تقييم المزرعة
- `result.html` — تقرير التقييم
- `owner.html` — مساحة صاحب المزرعة
- `admin.html` — مساحة فريق ريف

## التشغيل

المشروع عبارة عن صفحات HTML مستقلة مع JavaScript مضمّن، ولا يحتاج إلى build step.

للمعاينة محليًا يمكن فتح `index.html` مباشرة في المتصفح. إذا كانت بعض وظائف التخزين أو التنقل تختلف حسب المتصفح، شغّليه عبر خادم محلي بسيط.

## GitHub Pages

يمكن نشر المستودع باستخدام GitHub Pages، وستكون `index.html` هي الصفحة الرئيسية تلقائيًا.

> ملاحظة: البيانات التي ينشئها المستخدم في النموذج التجريبي تُحفظ محليًا في المتصفح (Local Storage) وليست قاعدة بيانات حقيقية.
